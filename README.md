# Motores de Bases de Datos

Proyecto académico para la implementación, configuración y validación de motores de bases de datos mediante Docker.

## Motores implementados

* MySQL 8.0
* PostgreSQL 17
* SQL Server 2022
* Oracle Database XE 21c

## Herramientas utilizadas

* Docker
* WSL
* Docker Compose
* DBeaver
* Git
* GitHub
