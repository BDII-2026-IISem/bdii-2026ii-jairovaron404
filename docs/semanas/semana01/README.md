# Semana 01 – Problema de datos y entorno reproducible

## Objetivo

Aplicar los fundamentos del problema de datos sobre el proyecto EnlaceExpress, identificando actores, procesos, reglas, entidades, atributos y relaciones, además de establecer el entorno de trabajo y el control de cambios del proyecto.

## Proyecto

**EnlaceExpress** es una plataforma orientada a la gestión de mensajería corporativa y envíos. El sistema permite manejar empresas, contactos, direcciones, mensajeros, rutas, tarifas, envíos, paquetes, seguimiento, pruebas de entrega y facturación.

## Objetivos trabajados

- Identificación de actores, procesos y reglas.
- Identificación de entidades, atributos y relaciones.
- Definición de la arquitectura y componentes relacionados con el sistema gestor de bases de datos.
- Preparación del entorno reproducible mediante Docker, Docker Compose y WSL.
- Organización del repositorio mediante Git y GitHub.
- Registro de decisiones y uso de herramientas de IA.
