# Semana 02 – Del dominio al modelo lógico

## Objetivo

Transformar el dominio de EnlaceExpress en un modelo conceptual y lógico, definiendo entidades, claves, dependencias, integridad y estructura de datos.

## Actividades

- Modelo conceptual y lógico.
- Claves y dependencias.
- Normalización y anomalías.
- Integridad.
- Diccionario de datos.

## Resultado

La estructura lógica del proyecto se implementó posteriormente en los cuatro motores:

- MySQL.
- PostgreSQL.
- SQL Server.
- Oracle.

## Evidencias

- `docs/diagramas/`
- `database/mysql/`
- `database/postgresql/`
- `database/sql-server/`
- `database/oracle/`

## Estado

Semana consolidada mediante los modelos, diagramas y estructuras implementadas en los cuatro motores.
